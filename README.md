# Wine-Quality-Prediction-System
The Wine Quality Prediction System Using Machine Learning successfully demonstrates the complete machine learning workflow, from data preprocessing and exploratory analysis to model development, evaluation and deployment through an interactive prediction interface.

The project analyzed multiple physicochemical characteristics of wine and investigated their relationship with wine quality. Different machine learning approaches were implemented and evaluated.

The regression experiments demonstrated that Gradient Boosting Regression achieved an R² of approximately 0.427, while the optimized Random Forest classification model achieved approximately 72% test accuracy.

Feature-importance analysis showed that alcohol, sulphates and volatile acidity were among the most influential variables in the Random Forest model.

Finally, an interactive prediction system was developed. For the demonstrated sample, the system predicted a quality score of 5, classified it as Average, and displayed a prediction confidence of 97.94%.

Overall, the project demonstrates the practical use of machine learning for wine quality prediction and provides a foundation that can be further improved through larger datasets, better handling of class imbalance, advanced algorithms and real-world deployment.
